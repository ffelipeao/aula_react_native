# Tutorial 6.1 — Cadastro de usuários no Firebase

Este tutorial **continua o projeto `MeuAppFirebase`** do [Tutorial 6](6-tutorial_autenticacao_firebase_email_senha.md). Antes de começar, confirme que o login, o menu ☰ e o botão **Sair** estão funcionando.

No Tutorial 6, o único jeito de criar um usuário era pelo console do Firebase. Agora o app terá três formas:

| Forma | Quem cadastra | Onde |
|---|---|---|
| 1. Console do Firebase | O professor ou administrador | **Authentication → Usuários → Adicionar usuário** (já feito no Tutorial 6) |
| 2. **Criar conta** | A própria pessoa, antes de entrar | Link na tela de login |
| 3. **Cadastrar usuário** | Alguém que já está logado | Nova opção no menu ☰ |

```text
Login ──► "Criar conta" ──► CriarConta ──► (conta criada e logada) ──► Início ☰
  ▲            │
  └── Voltar ◄─┘

Início ☰ ── Sobre o usuário
         ├── Contato
         └── Cadastrar usuário  (cria outra conta sem sair da sua)
```

Nenhuma biblioteca nova é necessária: tudo usa o `firebase` instalado no Tutorial 6.

## 2. Conferir o Firebase

Nenhuma credencial nova é necessária: o `.env.local` continua o mesmo. Confira apenas no console:

- **Authentication → Método de login → E-mail/senha** deve estar **ativado**. Sem isso, o cadastro retorna `auth/operation-not-allowed`.
- Em **Authentication → Configurações → Política de senha**, veja se há exigências além do mínimo de 6 caracteres. Se houver, as senhas cadastradas pelo app também precisarão atendê-las.

## 3. Uma segunda instância do Auth

Quando `createUserWithEmailAndPassword` cria uma conta, o Firebase **já entra com a conta nova**. Isso é ótimo para a forma 2 (a pessoa cria a própria conta e já entra), mas atrapalha a forma 3: quem está logado seria desconectado e entraria como o usuário recém-criado.

A solução é criar uma **segunda instância do Firebase** apenas para cadastrar outras pessoas. Ela guarda a sessão só na memória e não interfere no login principal.

Substitua `src/services/firebase.js`:

```js
import AsyncStorage from '@react-native-async-storage/async-storage';
import { getApp, getApps, initializeApp } from 'firebase/app';
import {
  getAuth,
  getReactNativePersistence,
  initializeAuth,
  inMemoryPersistence,
} from 'firebase/auth';

const firebaseConfig = {
  apiKey: process.env.EXPO_PUBLIC_FIREBASE_API_KEY,
  authDomain: process.env.EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN,
  projectId: process.env.EXPO_PUBLIC_FIREBASE_PROJECT_ID,
  storageBucket: process.env.EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET,
  messagingSenderId: process.env.EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID,
  appId: process.env.EXPO_PUBLIC_FIREBASE_APP_ID,
};

// Recupera uma instância já criada (recarregamento do Expo) ou cria uma nova.
function obterApp(nome) {
  return getApps().find((a) => a.name === nome) ?? initializeApp(firebaseConfig, nome);
}

function obterAuth(app, persistence) {
  try {
    return initializeAuth(app, { persistence });
  } catch {
    return getAuth(app);
  }
}

// Instância principal: guarda a sessão no aparelho (igual ao Tutorial 6).
const app = getApps().length === 0 ? initializeApp(firebaseConfig) : getApp();
const auth = obterAuth(app, getReactNativePersistence(AsyncStorage));

// Instância secundária: usada só para cadastrar outras pessoas.
// A sessão fica apenas na memória e não substitui o usuário logado.
const authSecundario = obterAuth(obterApp('secundario'), inMemoryPersistence);

export { auth, authSecundario };
```

> O `auth` principal funciona exatamente como antes. Nenhuma tela do Tutorial 6 precisa importar outra coisa.

## 4. Funções de cadastro

Para não repetir código nas duas telas, as regras de cadastro ficam em um serviço.

`src/services/usuarios.js`:

```js
import { createUserWithEmailAndPassword, signOut, updateProfile } from 'firebase/auth';
import { auth, authSecundario } from './firebase';

// Forma 2: a própria pessoa cria a conta e já fica logada.
export async function criarMinhaConta(nome, email, senha) {
  const { user } = await createUserWithEmailAndPassword(auth, email, senha);
  await updateProfile(user, { displayName: nome });
}

// Forma 3: um usuário logado cadastra outra pessoa sem perder a própria sessão.
export async function cadastrarOutroUsuario(nome, email, senha) {
  const { user } = await createUserWithEmailAndPassword(authSecundario, email, senha);
  try {
    await updateProfile(user, { displayName: nome });
  } finally {
    await signOut(authSecundario); // descarta a sessão do usuário recém-criado
  }
}

export function traduzirErroCadastro(codigo) {
  const mensagens = {
    'auth/email-already-in-use': 'Este e-mail já está cadastrado.',
    'auth/invalid-email': 'E-mail inválido.',
    'auth/weak-password': 'Senha fraca. Use pelo menos 6 caracteres.',
    'auth/password-does-not-meet-requirements': 'A senha não atende à política do projeto.',
    'auth/operation-not-allowed': 'Ative o login por e-mail/senha no console do Firebase.',
    'auth/network-request-failed': 'Sem conexão com a internet.',
  };
  return mensagens[codigo] ?? 'Não foi possível cadastrar. Tente novamente.';
}
```

- `createUserWithEmailAndPassword` cria a conta no Firebase Authentication.
- `updateProfile` grava o **nome** no campo `displayName` do usuário.
- Na forma 3, o `finally` garante que a instância secundária seja desconectada mesmo se `updateProfile` falhar.

## 6. Formulário reutilizável

As duas telas de cadastro pedem os mesmos dados. Por isso, criamos um único componente de formulário e cada tela informa o que fazer ao salvar.

`src/components/FormularioUsuario.js`:

```jsx
import { useState } from 'react';
import { ActivityIndicator, Pressable, Text, TextInput } from 'react-native';
import { traduzirErroCadastro } from '../services/usuarios';
import styles from '../styles/styles';

export default function FormularioUsuario({ textoBotao, onSalvar }) {
  const [nome, setNome] = useState('');
  const [email, setEmail] = useState('');
  const [senha, setSenha] = useState('');
  const [confirmacao, setConfirmacao] = useState('');
  const [erro, setErro] = useState('');
  const [sucesso, setSucesso] = useState('');
  const [carregando, setCarregando] = useState(false);

  async function salvar() {
    setErro('');
    setSucesso('');

    if (!nome.trim() || !email.trim() || !senha) {
      setErro('Preencha nome, e-mail e senha.');
      return;
    }
    if (senha.length < 6) {
      setErro('A senha deve ter pelo menos 6 caracteres.');
      return;
    }
    if (senha !== confirmacao) {
      setErro('As senhas não conferem.');
      return;
    }

    setCarregando(true);
    try {
      await onSalvar(nome.trim(), email.trim(), senha);
      setSucesso(`Usuário ${email.trim()} cadastrado!`);
      setNome('');
      setEmail('');
      setSenha('');
      setConfirmacao('');
    } catch (e) {
      setErro(traduzirErroCadastro(e.code));
    } finally {
      setCarregando(false);
    }
  }

  return (
    <>
      <TextInput style={styles.campo} placeholder="Nome" value={nome} onChangeText={setNome} />
      <TextInput
        style={styles.campo}
        placeholder="E-mail"
        value={email}
        onChangeText={setEmail}
        keyboardType="email-address"
        autoCapitalize="none"
      />
      <TextInput
        style={styles.campo}
        placeholder="Senha (mínimo 6 caracteres)"
        value={senha}
        onChangeText={setSenha}
        secureTextEntry
      />
      <TextInput
        style={styles.campo}
        placeholder="Confirme a senha"
        value={confirmacao}
        onChangeText={setConfirmacao}
        secureTextEntry
      />

      {erro !== '' && <Text style={styles.erro}>{erro}</Text>}
      {sucesso !== '' && <Text style={styles.sucesso}>{sucesso}</Text>}

      <Pressable style={styles.botao} onPress={salvar} disabled={carregando}>
        {carregando
          ? <ActivityIndicator color="#FFF" />
          : <Text style={styles.textoBotao}>{textoBotao}</Text>}
      </Pressable>
    </>
  );
}
```

> A senha é validada no app (tamanho e confirmação) para dar uma resposta rápida, mas o Firebase também valida. O app nunca grava a senha: ela é enviada diretamente ao Firebase.

## 7. Forma 2 — Criar conta pela tela de login

### 7.1 Tela Criar conta

`src/screens/CriarContaScreen.js`:

```jsx
import { Pressable, ScrollView, Text } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';
import FormularioUsuario from '../components/FormularioUsuario';
import { criarMinhaConta } from '../services/usuarios';
import styles from '../styles/styles';

export default function CriarContaScreen({ onVoltar }) {
  return (
    <SafeAreaView style={styles.container}>
      <ScrollView contentContainerStyle={styles.conteudo} keyboardShouldPersistTaps="handled">
        <Text style={styles.titulo}>Criar conta</Text>

        <FormularioUsuario textoBotao="Criar conta" onSalvar={criarMinhaConta} />

        <Pressable onPress={onVoltar}>
          <Text style={styles.link}>Já tenho conta — voltar ao login</Text>
        </Pressable>
      </ScrollView>
    </SafeAreaView>
  );
}
```

Depois que a conta é criada, o Firebase já faz o login. O `onAuthStateChanged` do `App.js` percebe a mudança e mostra a tela **Início**, sem nenhuma navegação manual.

### 7.2 Link na tela de login

Em `src/screens/LoginScreen.js`, faça duas alterações:

1. Receba a propriedade `onCriarConta` na função:

   ```jsx

   ```

2. Logo **depois** do `</Pressable>` do botão **Entrar** (antes de `</SafeAreaView>`), acrescente:


## 8. Forma 3 — Cadastrar usuário pelo menu

`src/screens/CadastrarUsuarioScreen.js`:

```jsx
import { ScrollView, Text } from 'react-native';
import FormularioUsuario from '../components/FormularioUsuario';
import { cadastrarOutroUsuario } from '../services/usuarios';
import styles from '../styles/styles';

export default function CadastrarUsuarioScreen() {
  return (
    <ScrollView style={styles.container} keyboardShouldPersistTaps="handled">
      <Text style={styles.titulo}>Cadastrar usuário</Text>
      <Text style={styles.texto}>
        Cadastre outra pessoa para acessar o sistema. Você continuará conectado com a sua conta.
      </Text>

      <FormularioUsuario textoBotao="Cadastrar" onSalvar={cadastrarOutroUsuario} />
    </ScrollView>
  );
}
```

> **Atenção à segurança:** neste exemplo, **qualquer usuário logado** pode cadastrar outras pessoas, e o menu só esconde a opção de quem não entrou. Para que apenas administradores possam cadastrar, é necessário um servidor confiável (por exemplo, **Cloud Functions** com o **Firebase Admin SDK**) que verifique o perfil de quem fez o pedido. Além disso, a tela **Criar conta** permite que qualquer pessoa se cadastre. Se o sistema for fechado, remova a forma 2 e use apenas as formas 1 e 3.

## 10. Atualizar o App.js

Substitua todo o conteúdo de `App.js`. As novidades estão marcadas com `// NOVO`.

```jsx
import 'react-native-gesture-handler';
import { useEffect, useState } from 'react';
import { ActivityIndicator, Pressable, Text, View } from 'react-native';
import { SafeAreaProvider } from 'react-native-safe-area-context';
import { NavigationContainer } from '@react-navigation/native';
import { createDrawerNavigator } from '@react-navigation/drawer';
import { onAuthStateChanged, signOut } from 'firebase/auth';

import { auth } from './src/services/firebase';
import styles from './src/styles/styles';
import LoginScreen from './src/screens/LoginScreen';
import CriarContaScreen from './src/screens/CriarContaScreen'; // NOVO
import HomeScreen from './src/screens/HomeScreen';
import SobreScreen from './src/screens/SobreScreen';
import ContatoScreen from './src/screens/ContatoScreen';
import CadastrarUsuarioScreen from './src/screens/CadastrarUsuarioScreen'; // NOVO

const Drawer = createDrawerNavigator();

function BotaoSair() {
  return (
    <Pressable style={styles.botaoSair} onPress={() => signOut(auth)}>
      <Text style={styles.textoSair}>Sair</Text>
    </Pressable>
  );
}

export default function App() {
  const [usuario, setUsuario] = useState(null);
  const [verificando, setVerificando] = useState(true);
  const [telaPublica, setTelaPublica] = useState('login'); // NOVO: 'login' ou 'criarConta'

  useEffect(() => {
    const cancelar = onAuthStateChanged(auth, (u) => {
      setUsuario(u);
      setVerificando(false);
      setTelaPublica('login'); // NOVO: ao sair, sempre volta para o login
    });
    return cancelar;
  }, []);

  if (verificando) {
    return (
      <View style={styles.centro}>
        <ActivityIndicator size="large" />
      </View>
    );
  }

  // NOVO: sem usuário, mostra Login ou Criar conta
  let telaSemLogin = <LoginScreen onCriarConta={() => setTelaPublica('criarConta')} />;
  if (telaPublica === 'criarConta') {
    telaSemLogin = <CriarContaScreen onVoltar={() => setTelaPublica('login')} />;
  }

  return (
    <SafeAreaProvider>
      {usuario ? (
        <NavigationContainer>
          <Drawer.Navigator screenOptions={{ headerRight: () => <BotaoSair /> }}>
            <Drawer.Screen name="Inicio" component={HomeScreen} options={{ title: 'Início' }} />
            <Drawer.Screen name="Sobre" component={SobreScreen} options={{ title: 'Sobre o usuário' }} />
            <Drawer.Screen name="Contato" component={ContatoScreen} />
            <Drawer.Screen
              name="CadastrarUsuario"
              component={CadastrarUsuarioScreen}
              options={{ title: 'Cadastrar usuário' }}
            />
          </Drawer.Navigator>
        </NavigationContainer>
      ) : (
        telaSemLogin
      )}
    </SafeAreaProvider>
  );
}
```

Como funciona:

- Antes do login, a troca entre **Login** e **Criar conta** é feita pelo estado `telaPublica`. São só duas telas, então não precisamos de outro navegador.
- Depois do login, o menu ☰ ganha a opção **Cadastrar usuário**.

## 11. Executar e testar

```bash
npx expo start --clear
```

**Forma 2 — Criar conta**

1. Na tela de login, toque em **Não tem conta? Criar conta**.
2. Tente salvar com campos vazios, com senha de 5 caracteres e com confirmação diferente: cada caso deve mostrar uma mensagem.
3. Preencha nome, e-mail e senha válidos e toque em **Criar conta** → o app deve abrir a tela **Início**.
4. Abra ☰ → **Sobre o usuário** e confira o nome.
5. No console, abra **Authentication → Usuários** e confirme o novo e-mail.
6. Toque em **Sair** e tente criar outra conta com **o mesmo e-mail** → "Este e-mail já está cadastrado."

**Forma 3 — Cadastrar usuário pelo menu**

1. Entre com qualquer conta e abra ☰ → **Cadastrar usuário**.
2. Cadastre uma pessoa nova → aparece "Usuário … cadastrado!" e o formulário é limpo.
3. Abra **Sobre o usuário**: o e-mail continua sendo **o seu**, não o da pessoa cadastrada.
4. Toque em **Sair** e entre com o e-mail e a senha que você acabou de cadastrar.

## 12. Problemas comuns

| Problema | Solução |
|---|---|
| `auth/operation-not-allowed` | Ative **E-mail/senha** em **Authentication → Método de login**. |
| "A senha não atende à política do projeto" | Confira as exigências em **Authentication → Configurações → Política de senha**. |
| Ao cadastrar pelo menu, o app troca para o usuário novo | Confira se `cadastrarOutroUsuario` usa `authSecundario`, e não `auth`. |
| `Firebase App named 'secundario' already exists` | Use a função `obterApp` do passo 3, que reaproveita a instância existente. |
| Nome aparece como "(não informado)" | Usuários criados pelo console não têm nome. Crie um usuário pelo app para testar. |
| Link "Criar conta" não faz nada | Confira se o `App.js` passa `onCriarConta` e se o `LoginScreen` recebe `{ onCriarConta }`. |

## 13. Desafios

1. Na tela de login, adicione **Esqueci minha senha** usando `sendPasswordResetEmail(auth, email)`.
2. Na tela **Início**, mostre "Olá, *nome*!" usando `auth.currentUser?.displayName`.

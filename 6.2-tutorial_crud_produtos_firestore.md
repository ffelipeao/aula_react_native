# Tutorial 6.2 — CRUD de produtos com Cloud Firestore

Este tutorial **continua o projeto `MeuAppFirebase`** do [Tutorial 6](6-tutorial_autenticacao_firebase_email_senha.md). Ele funciona com ou sem o [Tutorial 6.1](6.1-tutorial_cadastro_usuarios_firebase.md).

Vamos adicionar ao menu ☰ a opção **Produtos**, com as quatro operações de um CRUD:

| Operação | No app | No Firestore |
|---|---|---|
| **C**reate — cadastrar | Botão **+ Novo produto** | `addDoc` |
| **R**ead — consultar | Lista com busca por nome | `onSnapshot` |
| **U**pdate — alterar | Botão **Editar** | `updateDoc` |
| **D**elete — excluir | Botão **Excluir** | `deleteDoc` |

Os produtos ficam no **Cloud Firestore**, o banco de dados na nuvem do Firebase. Cada usuário enxerga **apenas os próprios produtos**, e os dados aparecem em qualquer aparelho em que ele entrar.

```text
Início ☰ ── Produtos ──► Lista (buscar, editar, excluir)
                           │
                           └── + Novo / Editar ──► Formulário ──► salvar ──► volta à lista
```

Os dados ficam organizados assim no Firestore:

```text
usuarios (coleção)
└── {uid do usuário} (documento)
    └── produtos (subcoleção)
        └── {id automático} → { nome: "Caderno", preco: 12.5, quantidade: 10, criadoEm: ... }
```

## 2. Criar o banco no console do Firebase

1. No console, menu à esquerda: **Criação (Build) → Firestore Database → Criar banco de dados**.
2. **Local:** escolha `southamerica-east1 (São Paulo)`. O local **não pode ser alterado** depois.
3. **Modo:** escolha **Iniciar no modo de produção** e clique em **Criar**.
4. Abra a aba **Regras (Rules)**, apague o conteúdo, cole as regras abaixo e clique em **Publicar**:

```js
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Cada usuário só lê e grava os produtos dentro do próprio uid.
    match /usuarios/{uid}/produtos/{produtoId} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

Como funcionam as regras:

- `request.auth != null` → só usuários logados acessam.
- `request.auth.uid == uid` → o `uid` do caminho precisa ser o do usuário logado. Assim, ninguém lê nem altera produtos de outra pessoa, mesmo modificando o app.
- Qualquer caminho não listado fica **bloqueado**.

> As **regras** são a proteção real dos dados. Esconder botões no app não impede o acesso, mas as regras são verificadas nos servidores do Firebase.
>
> Não use o "modo de teste", que libera o banco para qualquer pessoa durante 30 dias.

Nenhuma credencial nova é necessária: o `.env.local` do Tutorial 6 já contém o `projectId` usado pelo Firestore.

## 4. Funções do CRUD

Todas as operações com o banco ficam em um único arquivo. As telas apenas chamam essas funções.

`src/services/produtos.js`:

```js
import {
  addDoc,
  collection,
  deleteDoc,
  doc,
  onSnapshot,
  orderBy,
  query,
  serverTimestamp,
  updateDoc,
} from 'firebase/firestore';
import { auth, db } from './firebase';

// Caminho: usuarios/{uid}/produtos — os produtos do usuário logado.
function colecaoProdutos() {
  return collection(db, 'usuarios', auth.currentUser.uid, 'produtos');
}

// READ: chama "aoMudar" com a lista sempre que algo muda no banco.
// Retorna uma função que encerra a observação.
export function observarProdutos(aoMudar, aoFalhar) {
  const consulta = query(colecaoProdutos(), orderBy('nome'));
  return onSnapshot(
    consulta,
    (resultado) => aoMudar(resultado.docs.map((d) => ({ id: d.id, ...d.data() }))),
    aoFalhar,
  );
}

// CREATE
export function criarProduto(produto) {
  return addDoc(colecaoProdutos(), { ...produto, criadoEm: serverTimestamp() });
}

// UPDATE
export function atualizarProduto(id, produto) {
  return updateDoc(doc(colecaoProdutos(), id), { ...produto, atualizadoEm: serverTimestamp() });
}

// DELETE
export function excluirProduto(id) {
  return deleteDoc(doc(colecaoProdutos(), id));
}
```

- `addDoc` cria um documento com **id automático**.
- `onSnapshot` mantém a lista **em tempo real**: depois de salvar ou excluir, a tela atualiza sozinha, sem precisar recarregar.
- `serverTimestamp()` grava a data e a hora do servidor do Firebase.

## 6. Tela de lista (consultar, buscar e excluir)

`src/screens/ProdutosScreen.js`:

```jsx
import { useEffect, useState } from 'react';
import { ActivityIndicator, Alert, FlatList, Pressable, Text, TextInput, View } from 'react-native';
import { excluirProduto, observarProdutos } from '../services/produtos';
import styles from '../styles/styles';

function formatarPreco(valor) {
  return `R$ ${valor.toFixed(2).replace('.', ',')}`;
}

export default function ProdutosScreen({ navigation }) {
  const [produtos, setProdutos] = useState([]);
  const [busca, setBusca] = useState('');
  const [carregando, setCarregando] = useState(true);
  const [erro, setErro] = useState('');

  useEffect(() => {
    const cancelar = observarProdutos(
      (lista) => {
        setProdutos(lista);
        setCarregando(false);
      },
      () => {
        setErro('Não foi possível carregar os produtos.');
        setCarregando(false);
      },
    );
    return cancelar; // para de observar ao sair da tela
  }, []);

  const termo = busca.trim().toLowerCase();
  const filtrados = produtos.filter((p) => p.nome.toLowerCase().includes(termo));

  function confirmarExclusao(produto) {
    Alert.alert('Excluir produto', `Deseja excluir "${produto.nome}"?`, [
      { text: 'Cancelar', style: 'cancel' },
      {
        text: 'Excluir',
        style: 'destructive',
        onPress: () => excluirProduto(produto.id).catch(() => setErro('Não foi possível excluir.')),
      },
    ]);
  }

  function editar(produto) {
    // Envia só os campos simples para o formulário.
    const { id, nome, preco, quantidade } = produto;
    navigation.navigate('FormProduto', { produto: { id, nome, preco, quantidade } });
  }

  return (
    <View style={styles.container}>
      <TextInput
        style={styles.campo}
        placeholder="Buscar por nome"
        value={busca}
        onChangeText={setBusca}
      />
      <Pressable style={[styles.botao, styles.espaco]} onPress={() => navigation.navigate('FormProduto')}>
        <Text style={styles.textoBotao}>+ Novo produto</Text>
      </Pressable>

      {erro !== '' && <Text style={styles.erro}>{erro}</Text>}
      {carregando && <ActivityIndicator size="large" />}

      <FlatList
        data={filtrados}
        keyExtractor={(item) => item.id}
        ListEmptyComponent={!carregando && <Text style={styles.texto}>Nenhum produto encontrado.</Text>}
        renderItem={({ item }) => (
          <View style={styles.cartao}>
            <Text style={styles.nomeProduto}>{item.nome}</Text>
            <Text style={styles.texto}>
              {formatarPreco(item.preco)} · Estoque: {item.quantidade}
            </Text>
            <View style={styles.linha}>
              <Pressable style={[styles.botao, styles.botaoPequeno]} onPress={() => editar(item)}>
                <Text style={styles.textoBotao}>Editar</Text>
              </Pressable>
              <Pressable
                style={[styles.botao, styles.botaoPequeno, styles.botaoPerigo]}
                onPress={() => confirmarExclusao(item)}
              >
                <Text style={styles.textoBotao}>Excluir</Text>
              </Pressable>
            </View>
          </View>
        )}
      />
    </View>
  );
}
```

> A busca filtra a lista já carregada, no próprio aparelho. Para poucos produtos por usuário, isso é simples e rápido.

## 7. Tela de formulário (cadastrar e alterar)

A mesma tela serve para **cadastrar** e **editar**. Se ela receber um `produto` pela navegação, está editando; caso contrário, está cadastrando.

`src/screens/ProdutoFormScreen.js`:

```jsx
import { useState } from 'react';
import { ActivityIndicator, Pressable, ScrollView, Text, TextInput } from 'react-native';
import { atualizarProduto, criarProduto } from '../services/produtos';
import styles from '../styles/styles';

export default function ProdutoFormScreen({ navigation, route }) {
  const produto = route.params?.produto; // undefined = novo produto

  const [nome, setNome] = useState(produto?.nome ?? '');
  const [preco, setPreco] = useState(produto ? String(produto.preco).replace('.', ',') : '');
  const [quantidade, setQuantidade] = useState(produto ? String(produto.quantidade) : '');
  const [erro, setErro] = useState('');
  const [salvando, setSalvando] = useState(false);

  async function salvar() {
    const valor = Number(preco.trim().replace(',', '.'));
    const unidades = Number(quantidade.trim());

    if (!nome.trim()) {
      setErro('Informe o nome.');
      return;
    }
    if (preco.trim() === '' || !Number.isFinite(valor) || valor < 0) {
      setErro('Informe um preço válido (ex.: 12,50).');
      return;
    }
    if (quantidade.trim() === '' || !Number.isInteger(unidades) || unidades < 0) {
      setErro('A quantidade deve ser um número inteiro maior ou igual a zero.');
      return;
    }

    const dados = { nome: nome.trim(), preco: valor, quantidade: unidades };

    setErro('');
    setSalvando(true);
    try {
      if (produto) {
        await atualizarProduto(produto.id, dados);
      } else {
        await criarProduto(dados);
      }
      navigation.goBack(); // a lista se atualiza sozinha (onSnapshot)
    } catch {
      setErro('Não foi possível salvar. Verifique a conexão.');
      setSalvando(false);
    }
  }

  return (
    <ScrollView style={styles.container} keyboardShouldPersistTaps="handled">
      <Text style={styles.texto}>Nome</Text>
      <TextInput style={styles.campo} placeholder="Ex.: Caderno" value={nome} onChangeText={setNome} />

      <Text style={styles.texto}>Preço (R$)</Text>
      <TextInput
        style={styles.campo}
        placeholder="Ex.: 12,50"
        value={preco}
        onChangeText={setPreco}
        keyboardType="decimal-pad"
      />

      <Text style={styles.texto}>Quantidade</Text>
      <TextInput
        style={styles.campo}
        placeholder="Ex.: 10"
        value={quantidade}
        onChangeText={setQuantidade}
        keyboardType="number-pad"
      />

      {erro !== '' && <Text style={styles.erro}>{erro}</Text>}

      <Pressable style={styles.botao} onPress={salvar} disabled={salvando}>
        {salvando
          ? <ActivityIndicator color="#FFF" />
          : <Text style={styles.textoBotao}>{produto ? 'Salvar alterações' : 'Cadastrar'}</Text>}
      </Pressable>
    </ScrollView>
  );
}
```

O preço é gravado como **número** (`12.5`), e não como texto (`"12,50"`). Assim, ele pode ser ordenado e usado em cálculos. A vírgula é convertida para ponto antes de salvar e de volta para vírgula ao exibir.

## 8. Adicionar Produtos ao menu

O item **Produtos** do menu abrirá uma **pilha** com duas telas: a lista e o formulário. Assim, o formulário ganha o botão de voltar (←).

Em `App.js`, faça as quatro alterações abaixo.

**8.1 Imports** — acrescente junto aos outros:

```jsx
import { createDrawerNavigator, DrawerToggleButton } from '@react-navigation/drawer';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import ProdutosScreen from './src/screens/ProdutosScreen';
import ProdutoFormScreen from './src/screens/ProdutoFormScreen';
```

> A linha do `@react-navigation/drawer` **substitui** a que já existe (agora ela também importa `DrawerToggleButton`).

**8.2 Pilha de produtos** — logo abaixo de `const Drawer = createDrawerNavigator();`:

```jsx
const Stack = createNativeStackNavigator();
```

**8.3 Função `ProdutosStack`** — logo abaixo da função `BotaoSair`:

```jsx
function ProdutosStack() {
  return (
    <Stack.Navigator>
      <Stack.Screen
        name="ListaProdutos"
        component={ProdutosScreen}
        options={{
          title: 'Produtos',
          headerLeft: () => <DrawerToggleButton />, // mantém o ☰ nesta tela
          headerRight: () => <BotaoSair />,
        }}
      />
      <Stack.Screen
        name="FormProduto"
        component={ProdutoFormScreen}
        options={({ route }) => ({
          title: route.params?.produto ? 'Editar produto' : 'Novo produto',
        })}
      />
    </Stack.Navigator>
  );
}
```

**8.4 Item no menu** — dentro do `<Drawer.Navigator>`, logo abaixo da tela **Início**:

```jsx
            <Drawer.Screen
              name="Produtos"
              component={ProdutosStack}
              options={{ headerShown: false }}
            />
```

O `headerShown: false` esconde o cabeçalho do menu nessa opção, porque a pilha já exibe o próprio cabeçalho. Sem ele, apareceriam dois cabeçalhos.

## 9. Executar e testar

```bash
npx expo start --clear
```

1. Entre no app, abra ☰ → **Produtos**. A lista deve estar vazia.
2. **Cadastrar:** toque em **+ Novo produto** e salve `Caderno`, `12,50`, `10`. O app volta para a lista, que já mostra o produto.
3. Cadastre também `Caneta`, `2,00`, `50` e `Mochila`, `89,90`, `3`. A lista fica em ordem alfabética.
4. **Validação:** tente salvar com nome vazio, preço `abc` e quantidade `1,5`. Cada caso deve mostrar uma mensagem.
5. **Consultar:** digite `can` na busca. Deve aparecer apenas **Caneta**.
6. **Alterar:** toque em **Editar** no Caderno, mude o preço para `15,00` e salve. O título da tela deve ser **Editar produto**, e na lista deve haver só um Caderno, com o novo preço.
7. **Excluir:** toque em **Excluir** na Mochila. Toque em **Cancelar** e veja que nada muda. Repita e confirme.
8. **Console:** abra **Firestore Database → Dados** e navegue por `usuarios → {seu uid} → produtos`. Os documentos devem estar lá.
9. **Tempo real:** no console, altere a `quantidade` de um produto. O app atualiza sozinho.
10. **Isolamento:** saia e entre com **outro usuário**. A lista deve estar vazia. Volte ao primeiro usuário e veja os produtos dele.

## 10. Problemas comuns

| Problema | Solução |
|---|---|
| "Não foi possível carregar os produtos" / `permission-denied` | Confira se as regras do passo 2 foram **publicadas** e se o caminho no código é `usuarios/{uid}/produtos`. |
| `Unable to resolve @react-navigation/native-stack` | Execute `npm install @react-navigation/native-stack` e reinicie com `--clear`. |
| Aparecem dois cabeçalhos em Produtos | Falta `options={{ headerShown: false }}` no `Drawer.Screen` de Produtos. |
| O ☰ sumiu na lista de produtos | Confira o `headerLeft: () => <DrawerToggleButton />` no passo 8.3. |
| `db is not exported` / `getFirestore` não definido | Confira as duas linhas acrescentadas ao `firebase.js` no passo 3. |
| Salvar fica carregando sem terminar | O aparelho está sem internet. O Firestore aguarda a conexão para confirmar a gravação. |
| A lista não atualiza após salvar | Confira se a lista usa `observarProdutos` (com `onSnapshot`) e se o `useEffect` retorna `cancelar`. |

## 11. Desafios

1. Adicione o campo **categoria** ao produto (formulário, lista e banco).
2. Mostre no topo da lista o **valor total em estoque** (soma de `preco × quantidade`).
3. Na tela **Início**, mostre quantos produtos o usuário tem cadastrados.
4. Melhore as regras do Firestore para **validar os dados** no servidor. Por exemplo, aceitar apenas `preco is number && preco >= 0`. Pesquise sobre `request.resource.data`.
5. Pesquise como usar `where` do Firestore para buscar no servidor em vez de filtrar no aparelho.
